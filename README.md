# Glamis Dunes Rentals email signature

Images for the Glamis Dunes Rentals email signature used in Front.

- `glamis-brp-signature-logo.png` - Glamis Dunes Rentals logo with the BRP Experiences logo (shown at 170 x 151 px, stored at 2x for sharp display).
- `signature.html` - the signature HTML. `{{user.name}}` is filled in by Front with the sender's name.

Don't rename or move the logo file: live email signatures load it from this repo's raw URL.
